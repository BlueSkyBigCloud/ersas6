CSV Format Instructions:

The CSV file must have exactly 6 columns in the following order:

  1. zip_code (5-digit ZIP)
  2. state_code (2-letter state code, e.g., TX, NY)
  3. service_type (e.g., Unarmed Guard, Armed Guard)
  4. avg_price (average price, numeric)
  5. min_price (minimum price, numeric)
  6. max_price (maximum price, numeric)

Example:

75001,TX,Unarmed Guard,22.50,20.00,25.00
10001,NY,Armed Guard,40.00,35.00,45.00
